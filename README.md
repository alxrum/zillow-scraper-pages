# Zillow Scraper — pages

Статические страницы, которые открывает расширение Zillow Scraper (GitHub Pages):

- `welcome/` — открывается один раз после установки (закрепить расширение и где оно работает);
- `uninstall/` — открывается после удаления, отзыв уходит в Google-форму;
- `feedback/` — открывается кнопкой Report на экране ошибки и оценкой 1–3 звезды.

Privacy policy — на pinwisp.com: https://alxrum.github.io/zillow-scraper-privacy/

Иллюстрации: `tools/shots.html` → `node tools/render-shots.js` → `welcome/steps-1-2.png`, `welcome/step-3.png`.
Счётчик Umami стоит на welcome, uninstall и feedback; на privacy его нет.
